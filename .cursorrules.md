# PROJECT: Asisten Laporan Harian MagangHub BRIN
# Untuk: Bintang Respati Aryananda, S.T. - Teknik Metalurgi - MagangHub di BRIN

## TUJUAN
Buatkan web app lokal yang membantu membuat laporan harian MagangHub
yang akan di-copy-paste manual ke monev.maganghub.kemnaker.go.id
Aplikasi ini HANYA membantu menyusun draf tulisan. TIDAK boleh
melakukan absensi otomatis, login otomatis, atau pengisian palsu.

## TECH STACK
- HTML, CSS, JavaScript murni (tanpa framework berat)
- Tanpa backend, tanpa database. Simpan data di localStorage browser.
- Bisa jalan lokal dengan cara klik file index.html atau `npx serve .`
- Tampilan mobile-first, rapi, karena sering dibuka dari HP
- Warna tema: Biru BRIN / putih, bersih, profesional

## FITUR WAJIB
1. Header: Nama, MagangHub BRIN, Tanggal hari ini (otomatis)
2. Form Input Singkat:
   - Input Tanggal
   - Input 3 poin singkat: Apa yang dikerjakan hari ini? (textarea)
   - Dropdown: Lokasi / Kegiatan: Lab, Observasi, Bimbingan Mentor, Olah Data, Studi Literatur, Lainnya
3. Tombol GENERATE LAPORAN:
   - Hasilkan 3 kolom teks terpisah:
     a) Uraian Aktivitas - minimal 150 karakter, bahasa formal
     b) Pelajaran yang Diperoleh - minimal 150 karakter
     c) Kendala yang Dialami - minimal 150 karakter
   - Bahasa Indonesia formal, gaya mahasiswa magang riset metalurgi di BRIN
   - Jangan mengarang data angka / hasil uji yang spesifik. Pakai kalimat umum yang aman.
   - Isi harus beda-beda tiap generate, jangan template yang sama persis.
4. Penghitung Karakter Live:
   - Di bawah tiap kolom, tampilkan jumlah karakter: "128 / 100 karakter - Sudah Memenuhi Syarat"
   - Kalau <100, tampilkan warna merah: "Belum memenuhi syarat minimal 100 karakter"
5. Tombol Copy per kolom + Tombol Copy Semua
6. Tombol Simpan ke Riwayat: simpan ke localStorage dengan tanggal
7. Halaman Riwayat: list laporan per tanggal, bisa dibuka lagi, bisa hapus
8. Pengingat: Tampilkan banner kuning jam 20.00 WIB: "Jangan lupa isi laporan di monev.maganghub.kemnaker.go.id sebelum 23.59 WIB"
9. Tombol Export: Download semua laporan jadi file .txt

## ATURAN PENULISAN AI
- Gunakan sudut pandang "saya"
- Untuk Uraian: ceritakan urutan kegiatan, SOP, diskusi dengan mentor
- Untuk Pelajaran: apa yang dipahami, kenapa penting untuk riset metalurgi
- Untuk Kendala: kendala yang wajar (adaptasi alat baru, istilah teknis, dll) + cara mengatasinya dengan bertanya ke mentor. Jangan tulis kendala berat / mengeluh tentang instansi.
- Jangan pernah tulis: "saya tidak masuk", "saya bolos", "saya lupa absen"
